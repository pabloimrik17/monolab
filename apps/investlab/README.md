# InvestLab

React Router v8 investment tracker. Displays live stock quotes using the Finnhub API.

## Environment Setup

```bash
cp apps/investlab/.env.example apps/investlab/.env
```

Edit `.env` and add your [Finnhub API key](https://finnhub.io/).

## Development

```bash
nx run @m0n0lab/investlab:dev
```
